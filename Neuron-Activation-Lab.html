How to Find Out if an Artificial Neuron Activates

Goal: find out if a neuron in the hidden layer or the output layer activates.

What you need

  • The values coming into the neuron: from the input layer (i1, i2, …) or from a hidden layer (h1, h2, …)
  • The weight on each connection (w1, w2, …). The weight shows how reliable one neuron is for another neuron.
  • The neuron's bias, b. The bias shows how easily a neuron activates.

Method

  1. Multiply each incoming value by the weight on its connection. Add the results.
  2. Add the bias.
  3. Apply the step function to the answer:
    answer ≥ 0 → value = 1The neuron activates.
    answer < 0 → value = 0The neuron does not activate.

This rule is called the Heaviside step function.

Examples

For each example, work it out on paper first. Then pick your answer, and open the steps to check your work.
